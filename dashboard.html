RecruitFlow
An AI-powered Resume Intelligence Engine that automates resume screening, extracts structured candidate data, and recommends the best job roles using advanced AI analysis.
Key Features
Bulk Resume Upload
Upload multiple PDF and DOCX resumes simultaneously with drag and drop support
Smart Resume Parsing
Automatically extracts name, email, phone, skills, education and work experience
AI Analysis
Groq AI analyzes each candidate and generates professional summaries and insights
Role Recommendation
Suggests the best matching job roles with suitability percentage scores
Database Storage
All candidate data stored securely in MySQL with relational table structure
System Architecture
01 Resume Upload via Dashboard
02 FastAPI receives and validates files
03 Resume Parser extracts structured data
04 SQLAlchemy saves data to MySQL
05 Groq AI analyzes candidate profile
06 Role recommendations with scores saved
07 HR views results on dashboard
Database Schema
candidates — Core candidate info
education — Degree, institution, CGPA
experience — Work history, roles
skills — Technical and soft skills
ai_analysis — AI insights and scores

📄 Job Description — Software Developer
We are seeking a skilled and motivated Software Developer to design, develop, and maintain high-quality software applications. You will work closely with cross-functional teams to translate business needs into technical solutions, write clean code, and ensure optimal performance and scalability across our platforms.
Key Responsibilities
🔍
Analyze & Design
Collaborate with management, UX designers, and stakeholders to identify end-user requirements and create technical specifications.
💻
Write Code
Develop well-designed, testable, and efficient code using standard programming languages and frameworks.
🐛
Test & Debug
Troubleshoot, debug, and upgrade existing software, as well as execute thorough unit and integration testing.
🚀
Deploy & Monitor
Support the deployment of applications across systems and monitor performance in production environments.
📝
Document
Create and maintain technical documentation, architecture flowcharts, and user guides for future maintenance and scaling.
Required Qualifications
🎓 Education
Bachelor's degree in Computer Science, Software Engineering, or a related field (or equivalent practical experience).
🛠 Technical Skills
Proficiency in modern programming languages (JavaScript, Python, Java, or C++) and web standards (HTML5, CSS3).
⚙️ Tools & Frameworks
Familiarity with Agile methodologies, version control systems like Git/GitHub, and database systems.
🗣 Soft Skills
Strong analytical and problem-solving skills, coupled with excellent verbal and written communication.
